Hyperlink

A link has two parts — displayed text and embedded URL. mddiff word-diffs the visible text in place (it drops <a> from node-htmldiff’s atomic-tag set and neutralises the href so the link wrapper still matches), so a renamed link reads like any other inline edit and keeps its anchor. The one honest limit: a URL-only change (identical text) can only be signalled — struck + re-added — because both sides render the same.

Structural transforms

When a block keeps its text but changes SHAPE — a heading level, a list kind, a blockquote wrap, a paragraph turned into a bullet, an item nested — the identical text is NOT struck and re-added. It renders once, shown in each side’s own shape (size / glyph / indent) with a badge naming the change; only a real wording edit is marked.
